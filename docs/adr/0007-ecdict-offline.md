# ADR-0007：离线词库用 ECDICT 全量

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D7
- 关联：ADR-0008（SQLite 双库）、ADR-0001（Electron）

## 背景

查词需要释义数据。你现有的阅读软件自带翻译但**有额度限制**，这正是要解决的痛点之一。

## 决策

用 [ECDICT](https://github.com/skywind3000/ECDICT) 全量词库（约 77 万词条）离线内置，
经 `scripts/build_dict.py` 转成 `ecdict.db`。脚本进仓库，原始数据与产物不进仓库。

## 备选方案

- **在线词典 API**：数据质量可能更好，但有额度、要 Key、要联网、有隐私成本，
  而且把"断网可用"这条非功能需求直接作废。
- **内置常用子集 + 按需下载**：安装包更小，但多出一套下载器与状态管理，
  以及"没网时查不到"这一新的失败场景。

## 后果

- 好：无额度、无 Key、无网络；查询稳定在毫秒级；断网可用。
- 好：数据管线脚本本身是可复现、可测试、可单独运行的工程实践素材。
- 代价：安装包显著变大（预计 250 MB 量级）。
- 代价：ECDICT 的词条质量参差，释义需要"简洁 / 详细"两级呈现来兜住。
- 代价：许可与分发需要注意——不使用、不再分发受版权保护的其他词典内容。
- 遗留问题：`ecdict.db` 不进仓库但打包需要，**必须在 M4 之前决定**用 CI 现跑数据管线，
  还是把 db 作为 Release 资产随打包下载。

## 复核触发条件

- 实测安装包体积或构建时间不可接受 → 改为"常用子集 + 按需下载全量"；
- 若词库质量成为主要抱怨，考虑换源或叠加第二数据源（但不引入在线依赖）。
