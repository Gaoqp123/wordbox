# ADR-0005：加入生词本是显式动作

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D5
- 关联：ADR-0003（不监听剪贴板）、ADR-0004（历史与生词本分离）

## 背景

ADR-0004 决定了"查询"和"收录"在数据上分开，本条决定它们在交互上如何分开：
谁有权把数据写进生词本。

## 决策

只有显式动作才能收录：在快速查询窗或词条详情里按"加入生词本"。
收录时允许顺手编辑词条、写备注、打标签，并且——如果这次查询来自句模式——
**当时那句话会自动带上**，不需要手动复制粘贴。

## 备选方案

- **自动收录**（包括"查三次就自动收录"这类启发式）：省事，但会把判断权交给规则，
  而"这个词值不值得背"是只有你才能判断的事。

## 后果

- 好：生词本里的每一个词都是你主动做出的决定，这个列表才有被认真对待的价值。
- 好：收录动作本身就是录入界面，备注与语境在同一个动作里完成，成本极低。
- 代价：需要在查询窗里多一个按键；忘了收录就无法事后自动补救（但可从查询历史批量提升，F-15）。

## 复核触发条件

若查询历史与生词本的实际使用比例显示"想背的词几乎都来自历史批量提升"，
则说明单次收录的成本仍然偏高，应优化交互而不是改为自动收录。
