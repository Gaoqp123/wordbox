# ADR-0009：第一版不做手机端

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D9
- 关联：ADR-0001（Electron）、ADR-0004（数据分离）

## 背景

生词工具天然有"碎片时间复习"的想象空间，手机端看起来很合理。

## 决策

第一版只做 Windows 桌面端。手机端记为 P2（F-22），届时用"导出 JSON + 纯静态复习页"实现，
而不是再写一个原生应用。

## 备选方案

- **PWA 天然多端**：这恰恰是 v0.1 的原始方案，也是 ADR-0001 推翻它的原因——
  多端能力换不来系统级取词能力，而取词才是这个工具存在的理由。

## 后果

- 好：全部精力投向"取词 + 记词 + 复习"这条主链，不做重复的界面适配。
- 代价：出门在外无法复习；桌面端的复习节奏必须设计得足够灵活（不定量、不打卡）。

## 复核触发条件

若实际使用数据（复习发生的时间与设备）显示手机场景占比显著，则优先做 F-22 的静态导出页，
而不是重新评估技术栈。
