# ADR-0011：不抓取外部例句，只保存你遇到的原句

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D11
- 关联：ADR-0013（两个快捷键）

## 背景

卡片背面如果有一条例句，记忆效果通常更好。例句可以来自在线词典、例句库，或用 AI 生成。

## 决策

不抓取、不生成例句。改为：句模式下你选中的那句话随词一起保存，卡片上显示的就是
**你真正遇到它的那个场景**。

## 备选方案

- **爬取在线例句**：成本高（抓取、清洗、去重）、收益一般，且可能涉及版权。
- **AI 生成例句**：句子通顺但与你的真实语境无关，"背了用不上"。

## 后果

- 好：语境真实——你记得的往往是"当时读不懂的那句话"，而不是一个编造的示例。
- 好：零网络依赖，零版权风险；将来接 AI 做语境释义（F-20）时，输入已经存在。
- 代价：不是每个词都有原句；单词模式下收录的词没有语境，卡片只能显示词本身。

## 复核触发条件

若大量卡片因缺少语境而难以回忆，先看是否能把收录动作引导到句模式，再考虑引入例句来源。
