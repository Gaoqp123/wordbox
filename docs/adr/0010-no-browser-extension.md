# ADR-0010：不做浏览器扩展

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D10
- 关联：ADR-0012（取词程序无关）、ADR-0014（剪贴板兜底）

## 背景

浏览器是查词的主要场景之一。划词查询最"原生"的做法是写一个浏览器扩展。

## 决策

不做扩展。浏览器的取词走与阅读器、PDF、Office 完全相同的通用路径。

## 备选方案

- **浏览器扩展划词**：在浏览器内体验最好，但需要为多个浏览器分别维护，
  还要面对商店审核与浏览器 API 的持续变更，而它覆盖的场景已有通用方案可用。

## 后果

- 好：只维护一条取词路径；不必为三家浏览器各写一份代码。
- 代价：浏览器里的取词体验略逊于专用扩展——尤其 ADR-0014 之后，需要自己按一次 Ctrl+C。

## 复核触发条件

若浏览器取词在实际使用中占比很高，且"多按一次 Ctrl+C"被证明是显著摩擦，再评估扩展方案。
