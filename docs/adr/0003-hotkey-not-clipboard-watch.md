# ADR-0003：显式快捷键为主，剪贴板监听默认关闭

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D3
- 关联：ADR-0005（显式收录）、ADR-0014（剪贴板兜底）

## 背景

让取词零摩擦的另一个思路是监听剪贴板：你复制什么，我们就查什么。

## 决策

主路径是显式快捷键（默认 `Ctrl+Alt+D`）。剪贴板监听作为默认关闭的可选项保留（F-19），
且即便开启，命中的词也只进**查询历史**，不进生词本。

## 备选方案

- **剪贴板监听自动查询/收录**：零摩擦，但"复制 ≠ 想查词"。日常操作里 Ctrl+C 太频繁，
  自动收录会把生词本灌满你根本不打算背的词，最终导致整个功能被放弃。

## 后果

- 好：意图明确、数据干净——要查才查，要背才收。
- 代价：每次取词需要一次显式动作。当模拟按键不可用时这个代价会变成"多按一次 Ctrl+C"
  （见 ADR-0014），属于可接受范围。

## 复核触发条件

若实际使用中"忘记按快捷键"导致漏记严重，且剪贴板监听的过滤与冷却规则能被验证有效。
