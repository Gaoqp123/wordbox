# ADR-0002：不做内置阅读器

- 状态：已接受
- 日期：2026-10-04
- 规划条目：§2 D2
- 关联：ADR-0012（取词程序无关）

## 背景

要读 EPUB，最直觉的想法是自己写一个阅读器：取词就成了应用内部功能，选区、排版、
选中范围全都自己说了算，技术上也最简单。

## 决策

不做阅读器。WordBox 只做取词、记词与复习；阅读交给 Readest 等你已经用惯的工具。

## 备选方案

- **内置 EPUB / PDF 阅读器**：只覆盖"读书"一种场景，却要额外维护渲染、排版、书签、
  字号主题等一整套东西，并且会牺牲你现有的阅读体验。

## 后果

- 好：复用你已有的阅读器；覆盖浏览器、PDF、Office、聊天软件等所有程序，而不只是一种。
- 代价：取词被迫做成"程序无关"的外部行为，复杂度从"渲染文档"转移到"跨程序取词"——
  这部分风险最终在 ADR-0014 里落地。

## 复核触发条件

若"跨程序取词"在所有可行技术路线上都被证明不可接受，而阅读器内取词成为唯一出路。
