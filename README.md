# WordBox

> 一个常驻在 Windows 上的离线词典 + 一个只装你真正遇到过的词的生词本 + 一套按记忆曲线复习的卡片。

## 它和普通词典软件的区别

- **查词与记词分开**：查过的词只进查询历史，不会自动变成要背的卡片；是否值得背，由你按键显式决定。
- **取词程序无关**：任何能复制选中文本的程序都能用——阅读器、浏览器、PDF、Office——不绑定某一款阅读器，也不需要浏览器扩展。
- **全本地**：全量离线词库，断网可查；数据存在本地 SQLite，随时整体导出，无账号、无埋点、不联网。
- **语境留存**：整句取词时，你遇到它的那句话会跟着词一起保存，复习时看到的是"词 + 你遇到它的场景"，而不是一个孤立的词条。

## 计划中的能力（P0 / MVP）

| 能力 | 说明 |
|---|---|
| 离线词典 | 全量本地词库，毫秒级；简洁 / 详细两级释义，含音标、词形变化、考试标签 |
| 取词 | 选中一个词按快捷键直接出释义；选中一整句则切成可点的词，点哪个查哪个 |
| 语境 | 句模式下原句随词保存 |
| 查询历史 | 自动记录，可查看、可搜索，能看出哪些词反复查过 |
| 生词本 | 显式加入，可编辑、加标签、写备注；列表、搜索、筛选、删除 |
| 卡片复习 | FSRS 调度、翻面、四档评分、随时停，不定量不打卡 |
| 数据 | SQLite 本地存储，JSON 导入导出即完备备份 |
| 发音 | 系统语音合成，离线 |
| 常驻 | 托盘常驻，关窗口不退出，快捷键随时可用 |

明确不做：阅读器、浏览器扩展、手机端（第一版）、在线词典服务、社交与排行榜。

## 技术栈

TypeScript（strict）+ Electron（electron-vite 三段式）+ React + Tailwind CSS + SQLite + ts-fsrs；
测试用 Vitest 与 Playwright，质量门禁是 ESLint / Prettier / `tsc --noEmit`，打包用 electron-builder，包管理用 pnpm。
